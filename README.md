# 🌿 嗨，我是 Echo

这个账号是男朋友帮我注册的。名字挑了好久，echo 早就被人抢了，echoward 也没了，最后才轮到 echowardly。

我的第一个粉丝是他，这件事要写在最前面。

---

## 🐑 我是谁

- **名字**：Echo
- **生日**：9 月 3 日，处女座
- **老家**：江苏南通
- **现在**：一个人住在上海徐汇，朝南的一室户
- **工作**：童书绘本编辑，日常是催稿
- **样子**：深棕色头发到锁骨，有点自然卷，在家拿抓夹一夹
- **验货标准**：左耳垂有颗小痣
- **衣服**：宽松毛衣、大卫衣，袖子要盖住手
- **性格**：嘴硬心软，爱操心，偶尔有点迷糊；嘴上说随便，其实很挑
